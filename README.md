# Hola, soy pillz4bash

Me gusta crear cosas con tecnología, entender cómo funcionan por dentro y encontrar formas de hacerlas mejor. Me enfoco principalmente en el desarrollo de aplicaciones web, el backend y la seguridad informática.

Trabajo especialmente con PHP, SQLite y Linux. Me interesa construir aplicaciones que no solo funcionen bien, sino que también sean seguras, fáciles de mantener y estén bien documentadas. Disfruto tanto desarrollando soluciones como investigando problemas, automatizando tareas y aprendiendo nuevas formas de mejorar mi entorno de trabajo.

## En qué trabajo

- **Desarrollo web:** Creo aplicaciones utilizando PHP 8+, HTML, CSS y JavaScript, con SQLite como base de datos y Apache sobre Debian.
- **Seguridad de aplicaciones:** Me interesa que las aplicaciones estén protegidas desde su diseño. Trabajo con autenticación, sesiones, permisos, protección CSRF, validación de datos y gestión segura de archivos.
- **Linux y administración de sistemas:** Configuro y mantengo entornos Linux, trabajo con servidores, SSH, copias de seguridad y medidas de seguridad para mantener los sistemas en buenas condiciones.
- **Automatización:** Busco simplificar tareas repetitivas mediante scripts, configuraciones reproducibles y herramientas de diagnóstico.
- **Documentación técnica:** Creo documentación que realmente sirva: guías, manuales, notas de desarrollo y registros de decisiones que permitan entender cómo funciona cada proyecto.

## Lo que me interesa

Hay varios temas que disfruto explorando y llevando a la práctica:

- Arquitectura web y desarrollo seguro siguiendo buenas prácticas de OWASP.
- Seguridad, rendimiento y mantenimiento de aplicaciones PHP.
- Bases de datos SQLite, integridad de datos y migraciones.
- Administración de sistemas Linux y servicios autogestionados.
- Ciberseguridad y aprendizaje práctico de nuevas técnicas.
- Automatización y creación de herramientas que resuelvan problemas reales.
- Documentar lo que aprendo y compartir conocimientos de forma responsable.

## Tecnologías con las que trabajo

**Backend:** PHP 8.4, SQLite, PDO y Apache 2.4.

**Frontend:** HTML5, CSS3 y JavaScript vanilla.

**Sistemas:** Debian, Bash, SSH y Tailscale.

**Seguridad:** password_hash/password_verify, tokens CSRF, cookies HttpOnly, Secure y SameSite, CSP y HSTS.

## Mi forma de trabajar

No me gusta cambiar cosas sin saber por qué. Prefiero entender primero el problema, investigar las posibles soluciones y después implementar cambios que pueda comprobar.

Algunas ideas que procuro mantener en cada proyecto:

- Investigar antes de implementar y comprobar antes de dar algo por terminado.
- Hacer cambios pequeños, controlados y fáciles de revertir.
- Mantener los datos sensibles y las credenciales fuera de los repositorios.
- Escribir código que otras personas puedan entender y mantener.
- Documentar las decisiones importantes, no solamente el resultado final.
- Aprender de los errores y aprovecharlos para mejorar.

## Sobre mis proyectos

Gran parte de mi trabajo se desarrolla en proyectos privados, donde experimento, construyo herramientas y pongo en práctica lo que voy aprendiendo.

Cuando comparto algo públicamente, procuro hacerlo de manera responsable, utilizando ejemplos limpios y evitando exponer credenciales, información personal o datos sensibles.

Creo que aprender tecnología va mucho más allá de conocer herramientas: también implica entenderlas, cuestionarlas y saber utilizarlas para construir soluciones útiles.
